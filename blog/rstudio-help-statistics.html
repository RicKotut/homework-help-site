Statistics Methods & Software

R and RStudio Help for Statistics Assignments

Part of the Statistics Software and Methods Guide

RStudio homework help requests nearly always come from one of three places: a data file that won’t load, an error message that doesn’t explain itself, or output you don’t know how to read. R assignment help starts with knowing what each part of the RStudio window is for.

What the RStudio panes are for

  • Source: the script editor, where you write and save your code. Run a line with Ctrl+Enter (Cmd+Enter on a Mac).
  • Console: where code runs and where error messages appear.
  • Environment: the data and objects currently loaded. If it’s empty, your data isn’t loaded.
  • Files, Plots, Help: your folders, your graphs, and the documentation for any function.

A routine that works

  1. Load the data with read.csv().
  2. Check it with str(), head(), and summary().
  3. Fix the types. Turn group variables into factors with factor().
  4. Plot it with a boxplot so you can see what you’re testing.
  5. Run the test: t.test() for two groups, aov() for three or more.
  6. Read the key numbers: t and p, or F and Pr(>F).

Example: a one-way ANOVA in R

df <- read.csv("scores.csv")
str(df)
df$method <- factor(df$method)
boxplot(score ~ method, data = df)
fit <- aov(score ~ method, data = df)
summary(fit)
TukeyHSD(fit)

In the summary table, read the F value and Pr(>F). With the data from our ANOVA guide, F is 21.45 and Pr(>F) is about 0.0001. For two groups, use t.test(score ~ group, data = df).

The errors that stop most assignments

  • object not found. R is case-sensitive, so check the spelling. Also check that the line creating the object has actually been run.
  • cannot open file. R is looking in the wrong folder. Use Session > Set Working Directory > Choose Directory, or the Import Dataset button in the Environment pane.
  • there is no package called... Install it once with install.packages("name"), then load it each session with library(name).
  • Wrong degrees of freedom in aov(). If the group variable is numeric, R treats it as a number. Convert it with factor() and the degrees of freedom will be k − 1.

Common mistakes

Not reading the error message. The last line usually names the object, file, or function that failed. Start there.

Running code out of order. If a line depends on an earlier one, run the script from the top. Check the Environment pane to see what’s really loaded.
