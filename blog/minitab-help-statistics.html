Statistics Methods & Software

Minitab Help: Running and Reading the Output

Part of the Statistics Software and Methods Guide

Minitab is built so you can run a test in a few clicks, which makes the output the hard part. Good Minitab interpretation depends on knowing what the Session window is showing and which numbers belong in your answer.

How Minitab is organized

  • The Worksheet holds your data in columns.
  • The Session window shows the text output of every analysis you run.
  • Graphs open in their own windows.
  • The Stat, Graph, and Assistant menus are where you work. The Assistant menu walks you through the choices and produces a report card, which helps when you aren’t sure which test to use.

Menu paths for common tests

  • Descriptive statistics: Stat > Basic Statistics > Display Descriptive Statistics
  • Two-sample t-test: Stat > Basic Statistics > 2-Sample t
  • One-way ANOVA: Stat > ANOVA > One-Way
  • Correlation: Stat > Basic Statistics > Correlation
  • Regression: Stat > Regression > Regression > Fit Regression Model
  • Chi-square: Stat > Tables > Chi-Square Test for Association

The data layout trap

Minitab asks whether your data are stacked (all values in one column, with a second column of group labels) or in separate columns, one per group. Choose the option that matches your worksheet. A mismatch is the most common reason a test fails to run, or runs on the wrong data.

Reading a one-way ANOVA in the Session window

The output opens with the null hypothesis (all means are equal), the alternate hypothesis (at least one mean is different), and the significance level. Then comes the Analysis of Variance table, with the columns Source, DF, Adj SS, Adj MS, F-Value, and P-Value. After it, the Model Summary shows S and R-sq, and a table of means with grouping letters.

Example: the ANOVA from our worked guide

Factor: DF 2, Adj SS 493.3, Adj MS 246.7. Error: DF 12, Adj SS 138.0, Adj MS 11.5. Total: DF 14.

F-Value = 21.45, P-Value = 0.000.

Minitab shows 0.000 when the p-value is below 0.0005. It doesn’t mean zero, so write p < 0.001.

Write-up: the group means differ significantly, F(2, 12) = 21.45, p < 0.001. See the full calculation in our ANOVA guide.

Common mistakes

Reporting P = 0.000. A probability of exactly zero isn’t possible here. Report p < 0.001.

Choosing the wrong data layout. Check whether your columns are stacked or separate before you run anything.

Reading only the graph. The interval plot helps you see the pattern, but your answer should come from the table of numbers.
