SPSS Help: Running and Interpreting Common Tests

Part of the Statistics Software and Methods Guide

SPSS statistics help usually starts with the same complaint: you know which test you need, but SPSS has dozens of menus and an output window that prints every table at once. Once you know how the program is organized and which table to read, a statistical analysis in SPSS takes a few minutes.

How SPSS is organized

  • Data View is the spreadsheet. Each row is a case (a person, a trial) and each column is a variable.
  • Variable View is where each variable is defined: its type, its labels, and its level of measurement (Nominal, Ordinal, or Scale).
  • The Output Viewer shows the results. Everything you run is added to it.

Many wrong answers start in Variable View, with a group variable marked Scale instead of Nominal, or missing values coded as real numbers.

Menu paths for common tests

  • Descriptive statistics: Analyze > Descriptive Statistics > Frequencies or Descriptives
  • Independent-samples t-test: Analyze > Compare Means > Independent-Samples T Test
  • One-way ANOVA: Analyze > Compare Means > One-Way ANOVA (add Tukey under Post Hoc)
  • Chi-square: Analyze > Descriptive Statistics > Crosstabs, then Statistics > Chi-square
  • Correlation: Analyze > Correlate > Bivariate
  • Linear regression: Analyze > Regression > Linear

Step-by-step: running a test

  1. Set up your variables in Variable View. Code groups as numbers with value labels (for example 1 = Method A, 2 = Method B).
  2. Scan Data View for typos and missing values.
  3. Open the right test from the menu.
  4. Move variables into the correct boxes: the measured outcome goes in the test variable box, and the group variable in the grouping box. For a t-test, click Define Groups and enter the codes.
  5. Click OK and find the right table in the Output Viewer.

Reading an independent-samples t-test

Two groups of 10. Group Statistics shows means of 76.5 and 70.9.

In the Independent Samples Test table, Levene’s Test shows Sig. = .539. That is above .05, so assume equal variances and read the Equal variances assumed row.

That row gives t = 4.436, df = 18, Sig. (2-tailed) = .000, and a mean difference of 5.6.

Write-up: the groups differed significantly, t(18) = 4.44, p < .001, with means of 76.5 and 70.9.

Common mistakes

Reading the wrong row. Check Levene’s test first, then read the “Equal variances assumed” row or the “Equal variances not assumed” row, whichever applies.

Reporting .000 as p = 0. SPSS rounds to three decimals. Write p < .001.

Wrong measurement level in Variable View. Check that nominal variables are marked Nominal, because it changes which options SPSS offers.
