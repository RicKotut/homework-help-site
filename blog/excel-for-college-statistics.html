College Statistics

How to Use Excel for College Statistics

Part of the College Statistics Survival Guide

A lot of intro statistics courses expect you to use Excel without ever really teaching it. The good news: you only need a handful of functions and one add-in to handle most intro-level assignments.

Step 1: Turn on the Data Analysis ToolPak

This free built-in add-in unlocks most of the statistical tests you'll need. Go to File → Options → Add-ins, select "Excel Add-ins" in the dropdown, click Go, then check "Analysis ToolPak" and click OK. You'll now find a "Data Analysis" button under the Data tab.

Step 2: The core functions worth knowing

  • =AVERAGE(range) — the mean
  • =STDEV.S(range) — sample standard deviation (use this one for a sample, which is almost always what a homework dataset is)
  • =STDEV.P(range) — population standard deviation (only if you truly have the entire population, not a sample)
  • =CORREL(range1, range2) — correlation coefficient between two variables
  • =T.TEST(range1, range2, tails, type) — returns a p-value for a t-test directly

Worked example

Find the standard deviation of exam scores in cells A2:A31 (a sample of 30 students).

Type: =STDEV.S(A2:A31)

This gives you the sample standard deviation — the correct choice for homework datasets, which are almost always a sample rather than a full population.

Step 3: Running a full test via Data Analysis ToolPak

For a full t-test with all the output your assignment likely wants (means, degrees of freedom, p-value, critical values): Data tab → Data Analysis → choose the appropriate t-Test option (paired, or two-sample assuming equal/unequal variances) → select your two data ranges → OK. Excel generates a full output table you can interpret directly.

Common mistakes

Using STDEV.P instead of STDEV.S. This is the single most common Excel statistics mistake. Homework data is almost always a sample, not the full population — using the wrong formula gives a slightly different (and technically incorrect) answer.

Not checking which t-test type to select. The Data Analysis ToolPak offers different t-test options (paired, equal variances, unequal variances) — picking the wrong one changes your result. Match it to whether your data is paired and whether your groups have similar variances.
